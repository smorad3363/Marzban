# یادداشت انتشار v4.9.2

نسخه `v4.9.2` علاوه بر سامانه کامل سلسله‌مراتب مدیران، دو ناسازگاری آشکارشده در اجرای واقعی MySQL 8.0 را اصلاح می‌کند.

- کلیدهای ثابت جدول‌های مرجع و singleton دیگر `AUTO_INCREMENT` نیستند.
- hash توکن API با نوع دقیق `BINARY(32)` ذخیره می‌شود و unique index آن در MySQL معتبر است.
- migration افزایشی، قابل اجرای مجدد و سازگار با rollback برنامه به `v4.8.0` باقی می‌ماند.
