# یادداشت انتشار v4.9.1

نسخه `v4.9.1` سامانه سلسله‌مراتب مدیران را تکمیل می‌کند و خطای مهاجرت MySQL 8.0 نسخه `v4.9.0` را برطرف می‌کند.

## اصلاح مهم

- شناسه جدول‌های مرجع ثابت و singleton دیگر `AUTO_INCREMENT` نیست؛ بنابراین قیدهای `CHECK (id = 1)` در MySQL معتبرند.
- مهاجرت همچنان افزایشی، قابل اجرای مجدد و سازگار با داده‌های قدیمی است.

## قابلیت‌ها

- نقش‌های `Owner`، `Super Admin` و `Admin` با دسترسی محدود به subtree.
- انتقال و بازپس‌گیری اعتبار تراکنشی، idempotency و دفترکل تغییرناپذیر.
- توکن‌های API دارای scope، انقضا و لغو.
- تعلیق و بازیابی امن کاربران، عملیات bulk و طرح‌های نسخه‌دار.
- رابط مدیریتی سلسله‌مراتب، اعتبار، طرح‌ها و تمدید مستقل.

نسخه قابل بازگشت: `v4.8.0`.
