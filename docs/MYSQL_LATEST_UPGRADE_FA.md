# ارتقای امن MySQL مرزبان به آخرین نسخه

در حال حاضر `mysql:latest` نسخهٔ اصلی جدید MySQL است و نباید دیتادایرکتوری
`mysql:8.0` را مستقیم با آن اجرا کرد. ارتقای دیتای موجود باید مرحله‌ای باشد:

```text
8.0 → 8.4 → 9.7 → latest
```

## سرور دارای دیتای قبلی

ابتدا مطمئن شوید سرویس فعلی با نسخهٔ قبلی سالم بالا است. سپس:

```bash
marzban mysql-upgrade
```

این دستور پیش از تغییر نسخه، دو پشتیبان می‌سازد:

- دامپ منطقی همهٔ دیتابیس‌ها با checksum؛
- snapshot فیزیکی از `/var/lib/marzban/mysql` با checksum.

پشتیبان‌ها در مسیر زیر نگه‌داری می‌شوند:

```text
/opt/marzban/backup/mysql-upgrade-YYYYMMDDHHMMSS/
```

سپس MySQL را به‌ترتیب با `mysql:8.4`، `mysql:9.7` و `mysql:latest` اجرا، سلامت
هر مرحله و باقی‌ماندن داده را بررسی و در پایان سلامت Marzban را کنترل می‌کند.

اگر قبلاً `image: mysql:latest` گذاشته‌اید و MySQL بالا نمی‌آید، ابتدا image را
به `mysql:8.0` برگردانید تا همان دیتای 8.0 سالم بالا بیاید؛ بعد دستور بالا را
اجرا کنید. پس از شروع موفق یک مرحلهٔ ارتقا، image قدیمی‌تر را روی همان دیتادایرکتوری
اجرا نکنید؛ برای بازیابی از snapshot پیش از ارتقا استفاده کنید.

## نصب تازه

نصب تازه مستقیماً از `mysql:latest` استفاده می‌کند و نیاز به ارتقای مرحله‌ای ندارد.

## بازگشت برنامهٔ Marzban

بازگشت نسخهٔ برنامه، نسخهٔ دیتابیس را پایین نمی‌آورد:

```bash
marzban rollback v4.9.2
```

Downgrade خود MySQL به‌صورت in-place پشتیبانی نمی‌شود. برای بازگشت MySQL باید
سرویس‌ها متوقف و snapshot فیزیکی ساخته‌شده پیش از ارتقا در یک دیتادایرکتوری تمیز
بازیابی شود.
